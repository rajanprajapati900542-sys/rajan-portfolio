# Rajan Prajapati — Full Stack Developer Portfolio

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in Chrome/Edge/Firefox.
3. For best development experience, use VS Code + Live Server.

## Customize
- Replace the RP placeholder in the hero with your own professional photo.
- Update GitHub/LinkedIn/Instagram links in `index.html`.
- Replace `#` project links with your real Live Demo and GitHub URLs.
- Put your resume PDF in this folder as `resume.pdf`.
- Update email/phone if needed.

## Deploy
You can upload this folder to GitHub Pages, Netlify, Vercel, or any static hosting provider.
